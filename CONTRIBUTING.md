# Contributing to Centralynk

Thanks for your interest! Here's how to contribute.

## Quick start

```bash
git clone https://github.com/WaveyTimothy/Centralynk
cd Centralynk
cp .env.example .env
docker compose up -d
```

## How to contribute

1. Fork the repo
2. Create a branch: `git checkout -b fix/your-fix`
3. Make your changes
4. Test locally
5. Open a Pull Request

## Good first issues

Look for issues labeled `good first issue` — these are small, well-defined tasks perfect for first-time contributors.

## Areas where help is needed

- 🌍 New LLM engine integrations
- 📊 Better data visualizations  
- 🌐 Translations
- 📝 Documentation improvements
- 🐛 Bug fixes
